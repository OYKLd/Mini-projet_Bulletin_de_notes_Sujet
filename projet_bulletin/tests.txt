5.1 Erreur provoquée
  Modification : dans bulletin_v2.py, le float() autour de la saisie de la note
  de Python a été retiré : note_python = input("Note de Python (/20) : ")

  Message obtenu :
    Traceback (most recent call last):
      File "bulletin_v2.py", line 18, in <module>
        somme_ponderee = note_algo * coef_algo + note_python * coef_python + note_methodo * coef_methodo
                         ~~~~~~~~~~~~~~~~~~~~~~^~~~~~~~~~~~~~~~~~~~~~~~~~~
    TypeError: unsupported operand type(s) for +: 'float' and 'str'

  Type d'erreur : TypeError (opération entre types incompatibles).
  Cause : input() renvoie toujours du texte (str). note_python * coef_python
          donne donc une chaîne répétée 3 fois, et on ne peut pas additionner
          un nombre (float) et une chaîne (str).
  Correction : convertir la saisie avec float() :
          note_python = float(input("Note de Python (/20) : "))
  Le code correct a ensuite été remis dans bulletin_v2.py.
